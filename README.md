# Mods da Vibe Gifts

Todos os mods do Claude Code da Vibe Gifts num lugar só. Adicione esta vitrine uma vez e instale o que quiser. Quando sair um mod novo, ele aparece aqui sozinho.

| Mod | O que faz |
|---|---|
| [Hajime](https://github.com/vibe-gifts/hajime) | Um botão de play para os projetos que rodam em localhost no seu computador. |
| [WTF](https://github.com/vibe-gifts/wtf) | Painel que mostra, sem código e em português claro, o que a IA está construindo no seu projeto. |
| [Fila Render](https://github.com/vibe-gifts/fila-render) | Uma fila única para os renders de vídeo no Mac, com prioridade e ordem no painel. |

## Como adicionar a vitrine

Na caixa de mensagem de uma sessão no terminal:

```
/plugin marketplace add vibe-gifts/mods
```

Depois, para instalar um mod (troque `hajime` pelo nome do mod):

```
/plugin install hajime@vibe-gifts
```

Pelo terminal do sistema:

```bash
claude plugin marketplace add vibe-gifts/mods
```

```bash
claude plugin install hajime@vibe-gifts
```

No app desktop, clique em **+** ao lado da caixa de mensagem, depois em **Plugins** e em **Add marketplace**, informe `vibe-gifts/mods` e escolha os mods.
